# WHMCS-Dedicated-Server-Reseller-Module
WHMCS reseller provisioning module for 1Gbits Dedicated Servers.   Includes a full PHP module (`onegbits.php`), minimal API client wrapper, helper utilities, and comprehensive README with installation &amp; setup instructions.   Implements core WHMCS module functions: Create, Suspend, Unsuspend, Terminate, ChangePackage, TestConnection
